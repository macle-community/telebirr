# Full lesson manuscripts

These chapters are written for self-paced reading and hands-on practice.
Each day explains the core ideas, walks through an example, gives you an
exercise, and ends with review questions and a small follow-up task. The
chapters use the course starter and EthioShop capstone.

Find matching examples in the
[lesson source code index](./code/README.md). Code examples begin at Day 6;
earlier lessons use the starter project.
