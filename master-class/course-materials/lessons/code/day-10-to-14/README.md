# Days 10–14 — Requests, components, forms, storage

Examples run in the Taro starter unless noted.

- **Day 10:** `day-10/catalog-loader.tsx` demonstrates success/loading/error
  handling. The full catalog client is in
  [`final-project/frontend/src/pages/index/index.tsx`](../../../../final-project/frontend/src/pages/index/index.tsx).
- **Day 11:** `day-11/core-button.tsx` is the fallback when the MAUI source
  assets are not installed. Do not enable automatic MAUI copying until you
  have a compatible asset distribution and configured its documented path.
- **Day 12:** `day-12/filterable-list.tsx` demonstrates stable keys and
  derived filtering.
- **Day 13:** `day-13/contact-form.tsx` demonstrates local validation only.
- **Day 14:** `day-14/todo-page.tsx` demonstrates storage with the Taro
  synchronous storage API. Verify the API exists in the exact Macle plugin
  and runtime before using it on a device.
