# Lesson source code

These are lesson-by-lesson source examples that accompany the manuscripts.
Use them with the Taro/Macle [starter template](../../../starter-template/README.md).
They are not a second application and should not be copied wholesale into one
page: each example is a focused checkpoint.

## Use an example

1. Run `npm ci` in `starter-template/`.
2. Copy the day's `index.tsx` into `starter-template/src/pages/index/index.tsx`.
3. If the example includes `index.css`, copy it beside the page and ensure the
   page imports it.
4. Run `npm run typecheck`, `npm run build:macle`, then `npm run sim:macle`.
5. Keep a copy of your own work before replacing a page.

For examples with extra routes, backend files, or test data, follow that day's
README instead of replacing only the starter page.
