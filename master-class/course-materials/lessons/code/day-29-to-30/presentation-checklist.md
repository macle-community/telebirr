# Capstone presentation checklist

## Demo

- [ ] State the problem and identify the fictional/demo data.
- [ ] Start backend and frontend using documented commands.
- [ ] Show catalog, cart, and one mock order.
- [ ] Show one failure path and how the user recovers.
- [ ] Point out the backend-owned price calculation.

## Explain

- [ ] Which behavior is tested?
- [ ] What does `simulated: true` mean?
- [ ] Why is a client callback not proof of settlement?
- [ ] What would be required before a real payment integration?
- [ ] Which runtime/device combinations were not tested?

Never include real credentials, PINs, or personal financial data in your
presentation materials.
