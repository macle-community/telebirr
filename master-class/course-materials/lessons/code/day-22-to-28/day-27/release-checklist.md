# Release artifact checklist

- [ ] Clean build succeeds from the documented command.
- [ ] Build/compiler/plugin versions recorded.
- [ ] App routes match the intended route list.
- [ ] No local environment files, private keys, test tokens, or debug dumps.
- [ ] Assets and licenses reviewed.
- [ ] Device APIs and permission declarations verified against current docs.
- [ ] Backend URL uses the intended environment and secure transport.
- [ ] Mock checkout is not presented as a real payment integration.
- [ ] Simulator and supported-device test results recorded separately.
- [ ] Portal steps and account prerequisites verified with current official docs.

This checklist is not platform approval.
