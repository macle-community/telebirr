New to this? Common words explained

Macle: The app platform this course is for.

Course folder / repository: The folder containing the course files.

npm: A tool used to download and run this project's setup commands.

Runtime: The part of Macle that runs your built app.

Plugin: A helper that connects the starter's build tools to Macle.

Compiler: A tool that changes the files you write into files the app can run.

Configuration: A settings file that tells the app or build tool what to do.

Source code: The files you change to make the app do something.

Build: Preparing your changed files so the Macle simulator can run them.

Simulator: A practice environment that shows how the built app runs.

Page or screen: One view in the app, like the product list.

View: The visible screen area of the app.

Route: The name the app uses to find a page.

Component: A reusable piece of a screen, such as a button or text label.

Event: Something a person does, such as tapping a button.

State: Information the app remembers while it is open, such as a tap count.

API: A way for the app to ask another part of the platform or a server to do something.

Backend: A separate server that handles data or decisions the app should not control.

Client: The app running on the user's device.

Request / response: A message the app sends to a server, and the server's reply.

Catalog: A list of products. A cart is the list of products someone plans to order.

Order: The server's record of a requested purchase. In this course, it is only a pretend order.

Permission: Approval needed before an app can use something private, like location.

ID: A short name or number used to tell one item apart from another.

Authentication: Checking who someone is.

Authorization: Checking what someone is allowed to do.

Fallback: Another simple option to use when a feature is unavailable.

Compatibility: Whether a feature works with the version of Macle you are using.

Idempotency: Making sure repeating the same request does not accidentally repeat an action, such as creating an order twice.

Entitlement: A record that says what a user is allowed to access.

Verification: Checking that a result is genuine before trusting it.

Responsive layout: A screen layout that adjusts to fit different screen sizes.

Mock: A pretend result for practice; it does not perform the real-world action.

React and Taro: Tools this starter uses behind the scenes. You can follow the course without knowing them first.

TypeScript: JavaScript with extra checks that can catch some mistakes before you run the app.
